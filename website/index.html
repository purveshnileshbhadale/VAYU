About

What is VAYU?

VAYU is a next-generation AI voice assistant that runs natively on your desktop. Unlike cloud-only assistants, VAYU integrates directly with your operating system — controlling applications, managing files, browsing the web, executing code, and responding to hand gestures — all through natural voice, text, or gesture commands. Switch between Default, Research, and Professional modes to adapt the AI to your workflow.

Built with a modular plugin architecture and multi-provider AI fallback (Gemini → OpenRouter → Groq), VAYU ensures you always have a responsive, intelligent assistant at your command — even if one AI provider goes down.

Created by Purvesh Nilesh Bhadale — independently developed, maintained, and freely available for everyone.

Guide

User Manual

Everything you need to know to use VAYU effectively.

1. Installation & Setup

Windows: Download VAYU.zip, extract anywhere, and double-click start_vayu.bat. The script auto-installs dependencies and launches VAYU.

macOS: Download VAYU_mac.zip, run brew install portaudio, then pip install -r requirements.txt, then double-click start_vayu.command.

Requirements: Python 3.10+, a webcam (for gestures), and an internet connection for AI features.

2. First Run & API Keys

On first launch, the Setup Wizard appears. You'll need at least one AI provider key:

  • Google Gemini (primary) — get a free API key at aistudio.google.com
  • Groq (fallback) — free key at console.groq.com
  • OpenRouter (fallback) — key at openrouter.ai

Keys are saved locally in config/api_keys.json. You can change them anytime in Settings.

3. Operating Modes

VAYU has three modes switchable via voice, gesture, or the footer dropdown:

🔵 Default

Balanced mode with core tools: web search, file ops, system control, media, reminders, and general assistance.

🟣 Research

Unlocks deep web search, code analysis, file processing, self-coding agent, OpenCode integration, and paper creation.

🟢 Professional

Productivity-focused: email, calendar, reminders, system tools, window management, and business workflows.

4. Voice Interaction

VAYU uses Voice Activity Detection (VAD) — just speak naturally and VAYU listens when you're talking. No wake word or push-to-talk needed by default.

Tips for best results:

  • Speak clearly at a normal volume
  • Use natural language: "What's the weather in Tokyo?", "Open Spotify and play my playlist"
  • For complex commands, break them into steps
  • Say "shutdown" or "goodbye" to close VAYU

6. Camera & Cursor Control

Camera: Tap the 📷 button in the right panel. The camera overlay appears at 220×200 with live hand tracking. Gestures activate automatically.

Cursor Mode: With camera on, tap 🖱 CURSOR OFF to enable. Your index finger moves the mouse with smooth 55% responsiveness. Pinch and release → left click. Peace sign → right click. Tap again to disable.

Note: The camera must be ON before cursor mode can activate. Cursor runs at 30 FPS polling for responsive tracking.

7. Phone Remote Control

Control VAYU from your phone's browser — no app installation needed. Just follow these steps:

1

Launch VAYU on your PC — the web server starts automatically on port 5050.

2

Check the console output for the local URL (e.g., http://192.168.1.100:5050). If enabled, a public ngrok tunnel URL is also shown.

3

Open the URL on your phone's browser (same Wi-Fi for local URL, anywhere for tunnel).

4

Enter the device code (default: 8421, changeable in config/api_keys.json).

5

Control VAYU — type commands, tap quick-action buttons (Mute, Mode, Vol+, Chrome, Shutdown, Time, Weather), or tap the voice button (green) to speak using your phone's mic.

Note: The remote control uses an embedded HTTP server (web/web_control.py) with zero external dependencies. All communication stays local unless ngrok tunnel is enabled.

10. Tips & Troubleshooting

  • Camera not working? Make sure no other app (Zoom, OBS) is using the webcam. Restart VAYU.
  • Gestures not detected? Ensure good lighting. Avoid covering your hand. Keep your hand within the camera frame.
  • AI not responding? Check your API keys in Settings. VAYU falls back through Gemini → OpenRouter → Groq automatically.
  • Microphone issues? Check Windows microphone permissions. Try a different input device in Sound settings.
  • Slow performance? Close unused apps. Reduce camera resolution in Settings if needed.
  • Auto-start: Enable in Settings to launch VAYU minimized to the system tray on Windows boot.
  • Music control: VAYU can control Spotify, YouTube Music, VLC, and any media player via media keys.
